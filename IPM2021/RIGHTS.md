# Rights and Reuse

This release contains research material with different rights status.

The presence of a file in the package does not mean that every part of that file is covered by the same license.

## Material Created for the Reconstructed Release

Original documentation, mappings, manifests, and other material created by the release authors for this reconstructed release are available under CC BY 4.0 where the authors have the right to grant that license.

See `LICENSE.md`.

## Publication Era Source Material

The release preserves data from the publication era `IPM2021/` repository snapshot.

The reconstructed release does not assign a new license to those historical files and does not change their original rights status.

The publication era source archive remains preserved unchanged.

## External Website Content

`Evidence Corpus/evidence_corpus.jsonl.gz` contains text extracted from external websites.

This text is included for research, reproducibility, and inspection of the study evidence.

Copyright and other rights in the original pages remain with the corresponding rights holders.

This release does not transfer or grant rights in the original web content.

Source URLs are preserved where available.

Users are responsible for checking whether their intended reuse is allowed by applicable law, licenses, and source terms.

## Search and Crawl Metadata

`Evidence Corpus/crawl_metadata.csv` contains metadata recorded during evidence collection, including URLs, queries, page information, response metadata, and technical fields.

Some fields originate from external web servers or other services rather than from the release authors.

Their inclusion supports provenance and reproducibility and does not grant additional rights in third party content.

## Fact Check Source Material

The release contains statements, labels, URLs, and metadata from PolitiFact and RMIT ABC Fact Check.

These materials keep their original rights status.

They are not automatically covered by the CC BY 4.0 license for material created for this reconstructed release.

## Human Research Data

The release contains pseudonymous participant records.

These records include demographic information, judgments, task data, search activity, and questionnaire responses.

Internal worker identifiers are retained because they connect records within the study.

Do not attempt to identify or contact participants.

Do not combine these records with external information for the purpose of identifying participants.

Participant contributions are not automatically covered by the CC BY 4.0 license for material created for this reconstructed release.

## Historical Preservation

The verified earlier release versions and the publication era source archive remain preserved unchanged.

The current package consolidates reader facing historical documentation into the root README. The release manifest records source information, package paths, omissions, and added files.

## License Scope

`LICENSE.md` applies only where the release authors have the right to grant the stated license.

External website content, fact check source material, participant contributions, publication era files with separate rights status, and other third party material keep their original rights status.
